Sincronização GitHub

Configure as credenciais para sincronizar os dados do portfólio com o GitHub. O token é guardado apenas no browser (localStorage) e nunca em ficheiros.

Segurança: O token nunca é enviado para o servidor nem guardado em ficheiros. Fica apenas no localStorage deste browser.
Configurações da API GitHub
Cria em: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Permissões necessárias: Contents (Read & Write).
Sincronização de Dados

Ao sincronizar, o ficheiro js/data.js no GitHub é actualizado com todos os dados actuais. Na próxima visita de qualquer dispositivo, os dados serão carregados automaticamente.
